# Reken-werkbladen

Zelfstandige, printbare rekenwerkbladen voor Felix. Open `index.html` in de
browser; alles draait client-side (geen server nodig).


## Werkblad: Splitsen en optellen
- Genereert 20 sommen (`a + b`, tot 100) over meerdere A4-pagina's.
- Elk getal heeft een splitsboompje met vakjes voor tientallen en eenheden.
- Keuze uit: Gemengd, Met tientaloverschrijding, Zonder tientaloverschrijding.
- Knoppen: **Nieuwe sommen** en **Afdrukken / PDF** (A4, zonder marges).
